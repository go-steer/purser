# Acknowledged incompatible changes to the exported API since the last
# release tag. Read and enforced by dev/tools/verify-apidiff.
#
# One apidiff line per entry, exactly as the tool prints it under
# "Incompatible changes" but without the leading "- ". Blank lines and
# everything after a `#` are ignored. For example:
#
#   # #12: Options.Foo never had a caller outside the tests and its zero
#   # value was already the only supported one.
#   ./mtls.Options.Foo: removed
#
# An entry here is not a rubber stamp — it is a claim, made in the PR that
# breaks the symbol, that the break is intended and written down. Record
# the same change under Changed or Removed in CHANGELOG.md.
#
# Cutting a release empties this file: once the tag moves, these breaks
# sit behind the new baseline, and a leftover entry would silently permit
# a second, unrelated removal of a symbol that no longer exists.
#
# #28: LookupIdentity returned a found bit and took no context, so a
# lookup backed by a directory could neither report "could not tell" nor
# honor the request's cancellation; a proxy assertion during an outage
# drew 401 ErrAssertedCallerUnknown. It now returns an error
# (ErrAssertedCallerUnknown / ErrUnavailable) and takes the request's
# context. Nothing outside purser implements or calls it today —
# core-agent and mast carry their own pre-migration copies — so the
# break costs no consumer anything, and only gets dearer after phase 2.
./authn.IdentityLookup.LookupIdentity: changed from func(string) (github.com/go-steer/purser.Caller, bool) to func(context.Context, string) (github.com/go-steer/purser.Caller, error)
./authn/bearer.(*Auth).LookupIdentity: changed from func(string) (github.com/go-steer/purser.Caller, bool) to func(context.Context, string) (github.com/go-steer/purser.Caller, error)
