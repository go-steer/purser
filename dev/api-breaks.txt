# Acknowledged incompatible changes to the exported API since the last
# release tag. Read and enforced by dev/tools/verify-apidiff.
#
# One apidiff line per entry, exactly as the tool prints it under
# "Incompatible changes" but without the leading "- ". Blank lines and
# everything after a `#` are ignored. For example:
#
#   # #12: Options.Foo never had a caller outside the tests and its zero
#   # value was already the only supported one.
#   ./mtls.Options.Foo: removed
#
# An entry here is not a rubber stamp — it is a claim, made in the PR that
# breaks the symbol, that the break is intended and written down. Record
# the same change under Changed or Removed in CHANGELOG.md.
#
# Emptied in a follow-up PR once the release containing these breaks is
# tagged — not in the release PR, whose apidiff check still compares
# against the previous tag (CONTRIBUTING.md, "Cutting a release", step 7).
# After that the breaks sit behind the new baseline, and a leftover entry
# would silently permit a second, unrelated removal of a symbol that no
# longer exists.
#
# (empty — nothing has been broken since v0.4.0)
